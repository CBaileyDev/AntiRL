## Local checks

- `cargo test --workspace --all-features --locked`: 53 passing tests, one intentionally ignored paid/live-provider test. Default features: 49 passing, one ignored.
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`, `cargo fmt --all -- --check`, frontend ESLint/TypeScript and Prettier checks pass.
- Production frontend and default-feature native release builds pass. Vite still reports the large Babylon entry bundle; no unsupported performance claim is made.
- Playwright: three passing Chromium workflows covering provider consent and previews, opener routing, identity, import status, viewer controls, coach Markdown safety, scrolling/cancellation/export, typed practice actions and malformed evidence.
- Native release/WebView2 checks use an isolated profile and copies of real replays. [Import results](validation/native-hardening.json) verify original names, compressed frame round trip, unchanged/failed skipping, snapshot cleanup, tombstones, retry and unsafe opener-protocol denial. A two-file unchanged pass took 5.14 ms in this small fixture; this is not a 2,000-file benchmark.
- [Watcher results](validation/native-watcher.json) observe real IPC requests: a new filesystem import refreshes the library exactly once; an already-present copy refreshes it zero times.
- [Viewer results](validation/native-hardening-viewer.json) cover production CSP mount, five camera modes, playback and seeking. Screenshots were inspected. Rust additionally verifies suspended-process execution, migration rollback/backups, compressed storage, re-export tombstones, failure isolation, provider parameters, stream filtering, cancellation and synthetic OAuth signatures/refreshes.
- [Native contract results](validation/native-contracts.json) exercise the final release's typed practice creation, camelCase training arguments, session response, mode isolation and training catalog. The existing rank/refresh-budget script also passes and runs with `pnpm test`.

## Remaining external gates

Real SIWC registration/account eligibility/sign-in/refresh/inference and live paid OpenAI/NeoToken calls were not performed. OpenAI now documents [SIWC sign-in](https://developers.openai.com/siwc/token-sharing-open-source/sign-in); its existence differs from the original review's assumption. Synthetic tests cannot verify live eligibility. SIWC stays behind `chatgpt-siwc` until that gate passes.

Known citation IDs are extracted into metadata; invented IDs can still appear in free-form model prose. Bounded analytical documents retain JSON internally, and legacy service strings are classified into structured IPC errors. These are explicit implementation limits, not claims of a fully typed internal domain or verified model statements.

Hosted CI requires pushing this branch. Clean-machine installer behavior, hardware/frame-time benchmarks, long sessions and actual OS browser launch remain unverified. The opener path is tested with frontend mocks and native denial of unsafe schemes. Originals and the user's live profile/credentials were not changed. Historical validation ledgers retain their original results and should be read together with this checklist.
